# Nexo Foundation MVP

The MVP is not a complete CMS.

## Must have
- application kernel
- configuration
- PostgreSQL persistence
- migrations
- entities/repositories
- schema engine
- content entries
- revisions
- publishing
- identity
- authorization
- audit
- events
- REST API
- CLI bootstrap
- automated tests
- Docker development environment
- security baseline
- documentation

## Explicitly defer
- marketplace
- advanced AI agents
- billing
- complex visual builder
- multi-region cloud
- advanced search infrastructure

The goal is a stable foundation that can support those features later.
