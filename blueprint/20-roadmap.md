# Product Roadmap

## Phase 0 — Architecture
Vision, RFCs, domain model, security model, extension model, compatibility policy.

## Phase 1 — Kernel
Application kernel, configuration, DI, lifecycle, modules, events, errors, logging.

## Phase 2 — Data
PostgreSQL, repositories, entities, schemas, migrations, transactions.

## Phase 3 — Content
Content types, fields, entries, revisions, publishing, taxonomy, media.

## Phase 4 — Identity
Users, organizations, teams, roles, permissions, sessions, audit.

## Phase 5 — API
REST, GraphQL, webhooks, OpenAPI, authentication, rate limiting.

## Phase 6 — Admin
Dashboard, editor, schema builder, media, users, workflow, settings.

## Phase 7 — Extensions
Plugin SDK/runtime, themes, CLI, marketplace foundation.

## Phase 8 — AI
Provider abstraction, generation, semantic search, RAG, agents, MCP.

## Phase 9 — Cloud
Multi-tenancy, projects, deployment, backups, billing abstraction, observability.
