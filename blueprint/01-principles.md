# Architecture Principles

1. API-first.
2. Modular core.
3. Extension-first.
4. Schema-driven content.
5. Secure by default.
6. Backward compatibility matters.
7. Database portability where practical.
8. Events are first-class.
9. Observability is built in.
10. AI is an optional platform capability, not a hard dependency.
11. Stable public APIs; private internals can evolve.
12. Documentation and tests are part of the product.
